## 💻 Menjalankan Secara Lokal

1. Clone repository ini:
   ```bash
   git clone https://github.com/da133450-ux/dinda-portfolio.git
   cd dinda-portfolio
   ```

2. Buka file `index.html` langsung di browser Anda, atau jalankan server lokal:
   ```bash
   npx serve .
   ```
   *Akses via peramban di `http://localhost:3000`.*
